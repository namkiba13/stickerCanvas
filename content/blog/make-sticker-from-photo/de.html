Ein guter Sticker braucht drei Dinge: ein freigestelltes Motiv, eine weiße Kontur und eine PNG-Datei mit transparentem Hintergrund. Alles drei gelingt direkt im Browser, ohne das Foto auf einen Server hochzuladen. Diese Anleitung führt Sie durch den Sticker-Editor von 94 Tools.

Das richtige Foto wählen

  • Ein klares Motiv, das sich vom Hintergrund abhebt: Person, Haustier, Gegenstand oder Gericht.
  • Ein scharfes, gut beleuchtetes Foto, dessen Motivfarben sich vom Hintergrund unterscheiden.
  • Abstehende Haare, durchsichtige Objekte wie Gläser und unruhige Hintergründe können raue Kanten erzeugen oder Details verlieren.
  • Unterstützt werden JPG, PNG, WebP und HEIC-Fotos vom iPhone.

Schritt für Schritt zum Sticker

Der Editor hat eine englische Oberfläche; die Namen der Schaltflächen stehen unten in Fettschrift.

  1. Öffnen Sie Sticker aus Fotos erstellen und klicken Sie auf den Upload-Bereich oder ziehen Sie ein Foto hinein. Der Editor öffnet sich mit Ihrem Bild. Im Editor können Sie auch Upload image in der unteren Leiste verwenden.
  2. Klicken Sie auf das Foto, um es auszuwählen; das Eigenschaftenfeld erscheint. Öffnen Sie More actions und wählen Sie Remove background. Beim ersten Mal lädt der Browser ein Modell von etwa 46 MB; danach geht es schneller.
  3. Klicken Sie unter Style auf Add outline für die typische weiße Sticker-Kontur. Ändern Sie Farbe und Stärke (Regler Outline), aktivieren Sie einen Schatten, schneiden Sie mit Crop image zu oder fügen Sie den glänzenden Holo-Effekt hinzu.
  4. Für Text wählen Sie das Werkzeug Text in der unteren Leiste und passen Schriftgröße, Farbe und Textkontur an.
  5. Herunterladen: Save PNG unter More actions speichert nur den ausgewählten Sticker; Download canvas in der oberen Leiste exportiert das ganze Layout.

Transparente PNGs für Chats und Druck

  • Nach dem Freistellen erzeugt Save PNG eine Datei mit transparentem Hintergrund, die auf jedem Foto oder Dokument sauber aussieht.
  • Beim Export der ganzen Leinwand wird der Papierhintergrund mitgespeichert. Für Transparenz stellen Sie den Hintergrund vorher auf Transparent.
  • Messenger haben eigene Regeln für Größe und Format von Sticker-Paketen. Prüfen Sie die Vorgaben Ihrer App, bevor Sie ein Paket anlegen.
  • Für gedruckte Aufkleber verwenden Sie ein hochauflösendes Original, damit der Sticker beim Vergrößern scharf bleibt.

Häufige Probleme lösen

  • Raue Kanten: Versuchen Sie ein schärferes Foto, einen ruhigeren Hintergrund oder schneiden Sie vor dem Freistellen eng um das Motiv zu.
  • Teil des Motivs fehlt: Mit Restore background holen Sie das Original zurück; versuchen Sie dann ein anderes Foto.
  • Langsame Verarbeitung: Schließen Sie andere Tabs. Neuere Computer und Smartphones sind schneller.
  • Datenschutz: Fotos werden auf Ihrem Gerät verarbeitet und nie an eine Freistellungs-API gesendet. Löschen Sie an gemeinsam genutzten Computern danach die Websitedaten.
