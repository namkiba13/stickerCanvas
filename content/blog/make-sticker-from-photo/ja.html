よいステッカーに必要なのは、背景から切り抜いた被写体、周りを囲む白い縁取り、そして背景が透明なPNGファイルの3つです。どれもブラウザだけで作れ、写真をサーバーにアップロードする必要もありません。この記事では94 Toolsのステッカー作成ツールの使い方を順に説明します。

写真の選び方

  • 背景からはっきり区別できる被写体：人物、ペット、物、料理など。
  • ピントが合っていて明るく、被写体と背景の色が異なる写真。
  • なびく髪、グラスのような透明な物、ごちゃごちゃした背景は、輪郭が粗くなったり細部が欠けたりしやすくなります。
  • JPG、PNG、WebP、iPhoneのHEIC写真に対応しています。

ステッカーを作る手順

エディターの画面は英語です。ボタン名は太字で示しています。

  1. 写真からステッカー作成を開き、アップロード欄をクリックするか写真をドラッグ＆ドロップします。写真が入った状態でエディターが開きます。エディター内では下部ツールバーの Upload image も使えます。
  2. 写真をクリックして選択すると、プロパティパネルが表示されます。More actions を開き、Remove background（背景を削除）を選びます。初回はブラウザが約46MBの処理モデルをダウンロードします。2回目以降は速くなります。
  3. Style で Add outline をクリックすると、定番の白い縁取りが付きます。縁の色を変えたり、Outline スライダーで太さを調整したり、影を付けたり、Crop image で切り抜いたり、きらめく Holo 効果を加えたりできます。
  4. 文字を入れるには、下部ツールバーの Text ツールを選び、文字サイズ、色、文字の縁取りを調整します。
  5. ダウンロード：More actions の Save PNG は選択中のステッカーだけを保存し、上部バーの Download canvas はレイアウト全体を書き出します。

チャットや印刷に使える透過PNG

  • 背景を削除した後に Save PNG を使うと、背景が透明なファイルになり、どんな写真や資料にもきれいに重ねられます。
  • キャンバス全体をダウンロードすると、紙の背景も含まれます。透明にしたい場合は、先にキャンバスの背景を Transparent に設定してください。
  • メッセージアプリにはステッカーパックのサイズや形式に独自のルールがあります。パックを作る前にアプリのガイドラインを確認しましょう。
  • シールとして印刷する場合は、拡大しても粗くならないよう高解像度の元写真を使いましょう。

よくあるトラブルと対処法

  • 輪郭がギザギザ：より鮮明な写真やシンプルな背景を使うか、背景を削除する前に被写体の近くで切り抜いてください。
  • 被写体の一部が消えた：Restore background で元の写真に戻し、別の写真で試してください。
  • 処理が遅い：ほかのタブを閉じてください。新しいパソコンやスマートフォンほど高速です。
  • プライバシー：写真は端末内で処理され、背景削除APIに送信されることはありません。共用のパソコンでは、使い終わったらサイトのデータを削除しましょう。
