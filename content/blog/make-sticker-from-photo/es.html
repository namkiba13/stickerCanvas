Un buen sticker necesita tres cosas: el sujeto recortado del fondo, un borde blanco alrededor y un archivo PNG con fondo transparente. Puedes hacer las tres en el navegador sin subir la foto a ningún servidor. Esta guía te lleva paso a paso por el creador de stickers de 94 Tools.

Elige la foto adecuada

  • Un sujeto claro que se distinga del fondo: una persona, una mascota, un objeto o un plato.
  • Una foto nítida y bien iluminada, con colores distintos a los del fondo.
  • El pelo suelto, los objetos transparentes como vasos y los fondos recargados pueden dejar bordes irregulares o perder detalle.
  • Admite JPG, PNG, WebP y fotos HEIC de iPhone.

Crea tu sticker paso a paso

El editor tiene la interfaz en inglés; los nombres de los botones aparecen en negrita.

  1. Abre Crear stickers con fotos y haz clic en la zona de carga o arrastra una foto. El editor se abre con tu imagen. Dentro del editor también puedes usar Upload image en la barra inferior.
  2. Haz clic en la foto para seleccionarla y aparecerá el panel de propiedades. Abre More actions y elige Remove background. La primera vez, el navegador descarga un modelo de unos 46 MB; después es más rápido.
  3. En Style, pulsa Add outline para el clásico borde blanco. Cambia el color, ajusta el grosor con el control Outline, activa la sombra, recorta con Crop image o añade el efecto brillante Holo.
  4. Para añadir texto, elige la herramienta Text en la barra inferior y ajusta tamaño, color y contorno.
  5. Descarga: Save PNG en More actions guarda solo el sticker seleccionado; Download canvas en la barra superior exporta todo el diseño.

PNG transparentes para chats e impresión

  • Tras quitar el fondo, Save PNG crea un archivo con fondo transparente que queda limpio sobre cualquier foto o documento.
  • Al descargar todo el lienzo se incluye el fondo de papel. Para que sea transparente, cambia antes el fondo a Transparent.
  • Las apps de mensajería tienen sus propias reglas de tamaño y formato para paquetes de stickers. Revísalas antes de crear uno.
  • Para pegatinas impresas, parte de un original en alta resolución para que no se pixele al ampliarlo.

Soluciona problemas habituales

  • Bordes irregulares: prueba con una foto más nítida, un fondo más sencillo o recorta cerca del sujeto antes de quitar el fondo.
  • Desapareció parte del sujeto: pulsa Restore background para recuperar el original y prueba con otra foto.
  • Procesamiento lento: cierra otras pestañas. Los ordenadores y móviles más nuevos van más rápido.
  • Privacidad: las fotos se procesan en tu dispositivo y nunca se envían a una API de eliminación de fondo. En un ordenador compartido, borra los datos del sitio al terminar.
