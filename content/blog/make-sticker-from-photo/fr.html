Un bon sticker demande trois choses : un sujet détouré, un contour blanc tout autour et un fichier PNG à fond transparent. Vous pouvez tout faire dans le navigateur, sans envoyer la photo sur un serveur. Ce guide vous accompagne dans l’éditeur de stickers de 94 Tools.

Choisir la bonne photo

  • Un sujet net qui se détache du fond : une personne, un animal, un objet ou un plat.
  • Une photo nette et bien éclairée, dont les couleurs diffèrent de celles du fond.
  • Les cheveux fins, les objets transparents comme les verres et les fonds chargés peuvent laisser des bords irréguliers ou perdre des détails.
  • Formats acceptés : JPG, PNG, WebP et HEIC de l’iPhone.

Créer votre sticker étape par étape

L’éditeur est en anglais ; le nom des boutons est indiqué en gras.

  1. Ouvrez Créer des stickers à partir de photos, cliquez sur la zone d’import ou glissez-y une photo. L’éditeur s’ouvre avec votre image. Dans l’éditeur, vous pouvez aussi utiliser Upload image dans la barre du bas.
  2. Cliquez sur la photo pour la sélectionner : le panneau des propriétés s’affiche. Ouvrez More actions et choisissez Remove background. La première fois, le navigateur télécharge un modèle d’environ 46 Mo ; ensuite, c’est plus rapide.
  3. Dans Style, cliquez sur Add outline pour le contour blanc typique. Changez sa couleur, réglez l’épaisseur avec le curseur Outline, activez l’ombre, recadrez avec Crop image ou ajoutez l’effet irisé Holo.
  4. Pour ajouter du texte, choisissez l’outil Text dans la barre du bas, puis réglez la taille, la couleur et le contour du texte.
  5. Téléchargement : Save PNG dans More actions enregistre uniquement le sticker sélectionné ; Download canvas dans la barre du haut exporte toute la composition.

PNG transparents pour les messageries et l’impression

  • Après le détourage, Save PNG crée un fichier à fond transparent qui s’intègre proprement à n’importe quelle photo ou document.
  • L’export du canevas entier inclut le fond papier. Pour un fond transparent, réglez d’abord le fond sur Transparent.
  • Les messageries imposent leurs propres tailles et formats pour les packs de stickers. Consultez leurs consignes avant d’en créer un.
  • Pour des autocollants imprimés, partez d’un original en haute résolution afin que le sticker reste net une fois agrandi.

Résoudre les problèmes courants

  • Bords irréguliers : essayez une photo plus nette, un fond plus simple, ou recadrez au plus près du sujet avant le détourage.
  • Une partie du sujet a disparu : cliquez sur Restore background pour retrouver l’original, puis essayez une autre photo.
  • Traitement lent : fermez les autres onglets. Les ordinateurs et téléphones récents sont plus rapides.
  • Confidentialité : les photos sont traitées sur votre appareil et jamais envoyées à une API de détourage. Sur un ordinateur partagé, effacez les données du site ensuite.
