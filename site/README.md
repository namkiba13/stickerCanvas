# 94 Tools deployment

Vietnamese static tool pages live alongside the original Sticker Canvas app.
The deployed branch is `site/free-tools` in `namkiba13/stickerCanvas`.

## Build

Use Node 22 and the pnpm version declared in `package.json`.

```sh
corepack enable
pnpm install --frozen-lockfile
SITE_URL=https://your-domain.example pnpm run build:site
pnpm run lint
node --test tests/*.test.mjs
```

Serve `dist-site/` with directory indexes and real 404 responses. The Dockerfile
builds the site and serves it with nginx on port 80.

- `/` — homepage
- `/vietnamese-number-to-words/` — Vietnamese number-to-words, multiple lines
- `/word-counter/` — whitespace-token and Unicode-grapheme counts
- `/sticker-maker/` — sticker instructions and editor entry
- `/sticker-maker/editor/` — original browser-side editor
- `/about/` — privacy and source/license information
- Categories: `/tools/number|text|image/`. Other locales use the same slugs under `/<code>/`.
- Old Vietnamese slugs (`/doi-so-thanh-chu/`, `/dem-tu/`, `/tao-sticker/`, `/cong-cu/*`, `/gioi-thieu/`) 301 in `site/nginx.conf`.

The portal is generated by `build/website.mjs`; `site/logic.mjs` and
`site/tools.mjs` implement the two text tools. The number reader is pinned to
the upstream npm release 2.4.0, corresponding to the fork's initial source.
The word-counter fork is retained as a reference; counting is implemented with
native Unicode APIs rather than its original ASCII/UTF-16 assumptions.

## Coolify

- Project: `94 Free Tools` (`c1odckhbtz3wro1lbv0fbjt0`)
- Application: `94-tools` (`uqjvr9mvf4zqrmcofpqxpsbh`)
- URL: `https://94chat.app` (Cloudflare proxied, SSL Full). `www` and the old
  sslip URL return 301 to it from `site/nginx.conf`.
- Build pack: Dockerfile; port 80; health check `/`.
- `SITE_URL` is a build-time variable, used for canonical URLs and sitemap.
- Deployments are triggered manually through Coolify.
- Blog posts live in `content/blog/<key>/<locale>.html`, one file per locale (all 12 are required; the build fails otherwise): front matter between `---` lines (`title`, `description`, `date` as YYYY-MM-DD, optional `updated`, `tool` such as `/vietnamese-number-to-words/`, and `slug` to override the URL, which defaults to `<key>`), then the HTML body. The build adds the post to `<locale>/blog/`, the homepage, the matching tool page, hreflang, and the sitemap.

When moving domains, update the application domain and `SITE_URL`, rebuild,
and configure permanent redirects from the old URLs. Keep the same tool paths.
