# 94 Tools deployment

Vietnamese static tool pages live alongside the original Sticker Canvas app.
The deployed branch is `site/free-tools` in `namkiba13/stickerCanvas`.

## Build

Use Node 22 and the pnpm version declared in `package.json`.

```sh
corepack enable
pnpm install --frozen-lockfile
SITE_URL=https://your-domain.example pnpm run build:site
pnpm run lint
node --test tests/*.test.mjs
```

Serve `dist-site/` with directory indexes and real 404 responses. The Dockerfile
builds the site and serves it with nginx on port 80.

- `/` — homepage
- `/doi-so-thanh-chu/` — Vietnamese number-to-words, multiple lines
- `/dem-tu/` — whitespace-token and Unicode-grapheme counts
- `/tao-sticker/` — sticker instructions and editor entry
- `/tao-sticker/editor/` — original browser-side editor
- `/gioi-thieu/` — privacy and source/license information

The portal is generated by `build/website.mjs`; `site/logic.mjs` and
`site/tools.mjs` implement the two text tools. The number reader is pinned to
the upstream npm release 2.4.0, corresponding to the fork's initial source.
The word-counter fork is retained as a reference; counting is implemented with
native Unicode APIs rather than its original ASCII/UTF-16 assumptions.

- Deployments are triggered manually through Coolify.
- Blog posts live in `content/blog/<slug>.html`: front matter between `---` lines (`title`, `description`, `date` as YYYY-MM-DD, optional `updated` and `tool` such as `/doi-so-thanh-chu/`), then the HTML body starting at `<h2>`. The build adds the post to `/blog/`, the homepage, the matching tool page, and the sitemap.

When moving domains, update the application domain and `SITE_URL`, rebuild,
and configure permanent redirects from the old URLs. Keep the same tool paths.
